QUICK GUIDE

How to use the SAR workbench

  1. Select an area and acquisition. Choose a preset, click the map or enter custom coordinates. The catalog lists real Sentinel-1 acquisitions. Partial coverage is marked unsuitable.
  2. Start the workflow. Optionally connect GitHub for this tab, then choose “Start workflow” in the request dialog. This starts the selected request and shows its status. Alternatively, copy the encrypted request and follow the manual GitHub steps. Generating or copying a code alone starts nothing.
  3. Load the results. Follow the result download link, then use “Open results ZIP” or “Open backup”. To find an earlier run, connect GitHub and choose “Latest results”, or use “Open GitHub results”. Results remain outside Git history for up to 14 days. Raw imagery is temporary.
  4. Review candidates individually. Compare the radar image area, time reference and AIS uncertainty. A missing AIS match does not establish deliberate disablement.
  5. Check again later. GFW may not yet be available for recent acquisitions. “Recheck AIS context” uses saved candidates without requesting another radar image.

Up to six requests from 14 days are retained. Each radar image area is limited to 500 km² and 2,500 pixels per side, with at most three new image analyses per day. Choosing more presets does not start additional jobs. Radar processing uses the existing Copernicus allowance. Historical GFW context: Powered by Global Fishing Watch · CC BY-NC 4.0. The coastline overview is for orientation and does not replace a nautical chart.
