QUICK GUIDE

How to use the SAR workbench

  1. Select an area and acquisition. The catalog lists real Sentinel-1 acquisitions. Areas with only partial coverage are marked unsuitable.
  2. Confirm the request. Copy the encrypted request, open GitHub, select “Run workflow”, paste it into the single input field and start the run. Use the repository owner account (mowlsint).
  3. Load the results. Download the “sar-workbench-encrypted” artifact from the completed GitHub run. Open its ZIP file here using “Open backup”. Results remain outside Git history for up to 14 days. Raw imagery is temporary.
  4. Review candidates individually. Compare the radar image area, time reference and AIS uncertainty. A missing AIS match does not establish deliberate disablement.
  5. Check again later. GFW may not yet be available for recent acquisitions. “Recheck AIS context” uses saved candidates without requesting another radar image.

Up to six requests from 14 days are retained. The radar image area is limited to 500 km² and 2,500 pixels per side. Radar processing uses the existing Copernicus allowance.
